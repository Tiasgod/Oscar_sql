# Oscar - Banco de Dados

Bem-vindo à base de dados do **Oscar**!

Banco de dados do Oscar completo

Projeto desenvolvido para a disciplina de Banco de Dados utilizando SQL.

## Conteúdos Trabalhados

O objetivo da atividade é praticar:

* Criação de banco de dados
* Criação de tabelas
* Relacionamentos
* Inserção de dados
* Consultas SQL
* Funções agregadas
* Filtros e ordenações
* Joins
* Group By e Order By
